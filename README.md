The COLORS application allows users to login and then add and search for specific colors linked to that login specifically. You will only be able to see colors the logged in user has added, and they will stay even after closing the website.

Uses a mix of html, css, js, php, and a mySQL database.

No setup necessary, simply visit the url the website is hosted at to use it.

The application is hosted at http://colorslabcop4331.xyz/, and can be accessed there.
